# robosys2026
このリポジトリはロボシスの授業で使用するリポジトリを公開します。

[![test](https://github.com/s25c1003qn-ops/robosys2026/actions/workflows/test.yml/badge.svg)](https://github.com/s25c1003qn-ops/robosys2026/actions/workflows/test.yml)

三井のカーシェアーズ（旧カレコ）のベーシックプラン（旧料金システム）に基づき、車種クラス、利用時間、走行距離から利用料金（円）を自動計算するコマンドラインツールです。

## 機能
* **自動最安値適用**: 10分単位の時間料金と各種パック料金（6時間・12時間・24時間）を自動比較し、最も安くなる料金を算出します。
* **端数時間切り上げ**: 三井のカーシェアーズのシステム通りに10分未満の端数は自動的に10分単位へ切り上げて計算します
* **距離料金の自動加算**: 利用時間が6時間を超える場合、車両クラスに応じた1kmあたりの距離料金を自動加算します。
* **入力ミスの防止機能**: 入力の過不足やミスがある場合に、説明を出して安全に終了します。

## インストール方法

```bash
git clone https://github.com
cd robosys2026
chmod +x mituifee
```

### 使い方

引数には「車両クラス」、「時間」と「分」、時間が６時間を超える場合は「走行距離」を指定して実行します。

```bash
\$ ./mituifee <車両クラス> <時間> <分> [走行距離(km)]
```

* 車種クラスの引数が存在しないもの、または引数が不足・過剰な場合はエラーメッセージを表示し、終了ステータス'1'を返します。

---

### 引数の指定

|引数|内容|指定可能な値|
| :--- | :--- | :--- |
| **車両クラス** | 利用する車のクラス | `b`（ベーシック）、`m`（ミドル）、`mp`（ミドルプラス）、`p`（プレミアム）、`pp`（プレミアムプラス） |
| **時間** | 利用した時間（時間） | `0`以上の数値 |
| **分** | 利用した時間（分） | `0`以上の数値（10分単位に切り上げ） |
| **走行距離** | 走行した距離（km） | **6時間を超える場合は必須**（6時間以内の場合は省略可・加算無し） |

## 料金表（計算基準）

本ツールは以下の旧料金テーブルを基準に計算しています。

| クラス | 記号 | 10分料金 | 6時間パック | 12時間パック | 24時間パック | 距離料金（6時間超） |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| ベーシック | `b` | 150円 | 4,280円 | 5,700円 | 7,300円 | 21円/km |
| ミドル | `m` | 190円 | 5,280円 | 7,200円 | 8,500円 | 21円/km |
| ミドルプラス | `mp` | 220円 | 5,980円 | 8,300円 | 10,100円 | 21円/km |
| プレミアム | `p` | 290円 | 8,680円 | 9,900円 | 12,100円 | 23円/km |
| プレミアムプラス | `pp` | 520円 | 11,780円 | 13,900円 | 16,900円 | 25円/km |

### plus
標準出力から受け取った数値の合計を計算するコマンドです。

### 使い方
```bash
\$ SEQ 5 | ./PLUS
15
```
